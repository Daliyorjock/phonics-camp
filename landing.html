THE PROBLEM

为什么传统方法学了就忘

？

死记硬背 → 遗忘 → 再记 → 再忘。这个循环困住了无数英语学习者。市面上的 App 要么碎片化严重，要么忽视了语言习得的本质——听觉与韵律。

机械重复

传统背单词依赖显式记忆，艾宾浩斯遗忘曲线每一次都赢。没有韵律编码的语言输入，就像往漏水的桶里倒水。

纯视觉学习

单词卡和翻译对完全忽略听觉皮层——人类大脑为语言而生的脑区。看一百遍不如听一遍旋律。

碎片化输入

脱离音乐上下文的孤立单词无法构建语音和韵律模式。真正的语感来自连续的声音流，不是断开的单词碎片。

KEY INSIGHT · 核心洞察
人类天生通过韵律和重复习得语言——就像婴儿学母语一样。不是通过背单词表，而是通过音乐般的模式将语言刻入记忆。
THE METHOD

四阶段

学习循环

从聆听 → 音乐浸入 → 音形映射 → 主动召回，一次完整循环大约30秒，每天10分钟即可覆盖全部内容。

01

Hear First · 先听一遍

⏱ ~2.5秒 · 0.6x语速 · 纯人声

高保真 AI 人声清晰地朗读目标短语。你确切地知道马上要学什么——没有悬念，没有焦虑。2.5秒后自动进入下一阶段。

02

Earworm Jingle · 耳虫旋律

⏱ ~18秒 · 6轮音乐循环 · 人声渐进混入

第1-2轮：纯贝斯低音线建立律动。第3-4轮：人声以30%音量隐约浮现。第5-6轮：人声清晰可闻，与节奏完美同步。你的大脑以为在听歌——实际上正在习得语言模式。

03

Sound Bridge · 音形拆解桥

⏱ 用户自控 · 音节级着色 · 点击发声

每个音节按元音（蓝）/辅音（粉）着色，重音位置标有 ▼ 标记。逐音节点击即可听到发音。支持正常语速（1.0x）和慢速（0.55x）播放。在"听"与"写"之间建立精确映射。

04

Progressive Recall · 渐进召回

⏱ ~15秒 · 识别→填空→默写 · 三阶递进

三级递增难度。识别阶段（选择题）→ 填空阶段（补全字母）→ 默写阶段（Game Drop 字符下落游戏）。你只面对自己准备好了的挑战，不给"没学过"的测试。

DESIGN PHILOSOPHY

反课本设计

四条法则，每条都在颠覆传统语言教育。

隐式统计学习

大脑通过重复暴露自动提取语言模式，无需任何显式教学。就像婴儿听大人说话——听多了自然就会。

音乐纹理编码

语言信息嵌入音乐载体，同时激活听觉皮层+运动皮层——双通道记忆编码，比单一通道记忆效果提升40-60%。

耳虫即记忆

大脑无法停止重播洗脑旋律。每一次不自觉的脑内循环，都是一次免费的被动记忆巩固。你睡觉时它在工作。

不展示词典/音标/翻译

全界面无中文翻译、无音标符号、无语法解释。用户感觉在"听音乐"而不是"学英语"。反本能但更有效。

CORE FEATURES

六大引擎

，一个体验

每个组件独立设计，无缝集成。纯前端实现，零外部依赖。

耳虫音乐引擎

向量合成器+16步贝斯音序器。4种预设音色（mellow/pluck/pad/bass）。6轮人声渐进混入，Web Audio API 实时合成。

Sound Bridge 音形桥

音节级着色拆解。元音蓝色、辅音粉色、重音▼标记。逐音节点击发声，正常/慢速双模式。在听觉和视觉间精确映射。

渐进召回测试

识别→填空→默写三级递进。错误自动纠偏而非惩罚。识别错误→重播Jingle，填空错误→显示正确答案1.5秒后收起。

Leitner Box 间隔复习

5级间隔盒：L0→L1→L2(1天)→L3(3天)→L4(7天)→✅掌握。答错回退L0。localStorage持久化，刷新不丢进度。

Game Drop 字符下落

短语字母从顶部下落，9秒倒计时。正确键入→绿色闪烁+音效+得分。错误→红色抖动+重置。将拼写测试变成微型游戏。

人声融合引擎

预生成MP3 via Microsoft en-US-AriaNeural（业界评分最高英语女声）。44段音频Base64内嵌。Web Audio API 变速播放(0.55x-1.0x)。
