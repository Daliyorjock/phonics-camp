THE PROBLEM

为什么传统方法学了就忘？

死记硬背 → 遗忘 → 再记 → 再忘。这个循环困住了无数英语学习者。市面上的 App 要么碎片化严重，要么忽视了语言习得的本质——听觉与韵律。

背了用不上

背了8000个单词，日常交流还是张嘴卡壳。因为你背的都是低频词。DeepLingual 按语料库频率智能整合——先学覆盖90%日常交流的核心词。

拼写无规律

英语拼写有内在逻辑，但没人教过你。元音组合(ai/ea/ou)的发音规则、罗马音拆解方案，让每个音节都变得可预测。

越学越焦虑

考试压力、deadline焦虑、背不完的挫败感。大脑在紧张状态下根本无法高效学习。你需要的是放松和韵律——让大脑自己完成习得。

KEY INSIGHT · 核心洞察
人类大脑在放松、韵律、模式识别三重状态下语言习得效率最高。高频词整合 + 拼读规则 + 词根逻辑 + 耳虫旋律——四条通道同时运转，不是"学习"，是大脑的自然习得。
THE METHOD

四阶段学习循环

从聆听 → 音乐浸入 → 音形映射 → 主动召回，一次完整循环大约30秒，每天10分钟即可覆盖全部内容。

01

Hear First · 先听一遍

⏱ ~2.5秒 · 0.6x语速 · 纯人声

高保真 AI 人声清晰地朗读目标短语。你确切地知道马上要学什么——没有悬念，没有焦虑。2.5秒后自动进入下一阶段。

02

Root Rhythm · 词根韵律

⏱ ~18秒 · 6轮旋律循环 · 人声渐进混入 · 自然习得

重复的洗脑旋律让大脑无法主动"忘记"。第1-2轮纯贝斯线建立律动基底。第3-4轮人声30%隐约浮现，语感开始自然形成。第5-6轮完整呈现——语感+发音+拼写在无意识中内化。你没在学，你在"听歌"。

03

Morph Bridge · 词素拆解桥

⏱ 用户自控 · 元音罗马音拆解 · 点击发声

元音组合按罗马音方案拆解：aɪ(eye) / iː(see) / eɪ(say) / oʊ(go)。每个元音组合着色标记，逐音节点击发声。从"看到单词瞎念"到"看到任何单词都知道怎么读"——拼读规律一次性打通。

04

Context Drop · 环境运用

⏱ ~15秒 · 词根识别→语境填空→完整拼写 · 三阶递进

识词阶段验证词根词缀理解。语境填空阶段在真实句子中运用词汇——不是孤立的单词，而是"这个词在这个场景下就该这么用"。默写阶段(Game Drop)把拼写变成节奏游戏。错误不惩罚，而是触发词素拆解辅助。

DESIGN PHILOSOPHY

反课本设计

四条法则，每条都在颠覆传统语言教育。

高频词智能整合

不按字母顺序，不按教材章节。DeepLingual 按 COCA/BNC 语料库频率智能编排——先学每天都会遇到的词，让每一次学习都有即时回报。

拼读拼写方案

元音罗马音拆解(aɪ/iː/eɪ/oʊ)+辅音组合规律。不是音标——是一套直接映射到字母的发音规则。看到不认识的词也能读出来，听到没见过的词也能拼个八九不离十。

词根词缀环境运用

前缀=方向/位置，词根=核心含义，后缀=词性/功能。理解 re-(back)+spect(look)="回头看→尊重"。每个词根在真实语境中呈现，不是背定义，是理解"为什么"。

耳虫无压力习得

18秒一段旋律，6轮循环。大脑无法停止内部重播——每一次脑内循环都是一次免费的被动复习。没有考试压力，没有deadline焦虑。语感和词汇量在放松中自然生长。

CORE ENGINES

六大引擎，一个体验

每个组件独立设计，无缝集成。纯前端实现，零外部依赖。

渐进语境测试

词根识别→语境填空→完整拼写三级递进。每个词在真实句子中呈现，不是孤立抽背。错误自动触发词素拆解+韵律重播，把失误变成学习机会。

Leitner Box 智能间隔复习

5级记忆盒自动调度：当天→1天→3天→7天→永久掌握。答错自动回退，每次遗忘都触发更深层编码。localStorage 持久化，刷新不丢。

Game Drop 语境拼写

在真实句子中完成拼写——字母从顶部下落，9秒倒计时。正确→绿色闪烁+得分音效。错误→自动显示元音拆解+词根分解。拼写变成节奏游戏。

耳虫韵律引擎

W3C Web Audio API 实时合成16步音序器 + 4种音色(mellow/pluck/pad/bass)。人声渐进混入(0%→30%→100%)×6轮循环。让每个词变成"停不下来"的耳朵虫。
