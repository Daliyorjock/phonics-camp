THE PROBLEM

为什么传统方法学了就忘？

死记硬背 → 遗忘 → 再记 → 再忘。这个循环困住了无数英语学习者。市面上的 App 要么碎片化严重，要么忽视了语言习得的本质——听觉与韵律。

低效记忆

90%的交流只用2000个高频词，但传统方法让你背8000个却张不开嘴。不是词汇量不够，是没抓住频率命脉。

拼写靠硬背

没有词根词缀的底层逻辑，每个词都是孤岛。真正高效的拼写来自对构词规则的理解——把单词拆成可预测的模块。

学了就忘

没有间隔复习系统，遗忘曲线是单向的。DeepLingual 的 Leitner Box 让每次遗忘都变成下一次更深的记忆。

KEY INSIGHT · 核心洞察
人类大脑通过韵律、频率、构词逻辑三重通道习得语言。高频词+耳虫旋律+词根拆解——三条路径同时运转，记忆不是'记下来'，而是'长进去'。
THE METHOD

四阶段学习循环

从聆听 → 音乐浸入 → 音形映射 → 主动召回，一次完整循环大约30秒，每天10分钟即可覆盖全部内容。

01

Hear First · 先听一遍

⏱ ~2.5秒 · 0.6x语速 · 纯人声

高保真 AI 人声清晰地朗读目标短语。你确切地知道马上要学什么——没有悬念，没有焦虑。2.5秒后自动进入下一阶段。

02

Root Rhythm · 词根韵律

⏱ ~18秒 · 6轮音乐循环 · 人声渐进混入

第1-2轮建立律动基底，词根按音节嵌入贝斯线。第3-4轮人声30%渐入，拼写与发音形成同步映射。第5-6轮完整人声呈现。大脑以为在听歌——实际上词根构词逻辑正在被深层编码。

03

Morph Bridge · 词素拆解桥

⏱ 用户自控 · 词根/词缀级着色 · 点击发声

每个词根/词缀按功能着色——前缀(青)、词根(蓝)、后缀(粉)。重音▼标记。逐级点击发声。在词素结构、拼写规则、发音规律之间建立三位一体映射。

04

Progressive Recall · 渐进召回

⏱ ~15秒 · 识别→填空→默写 · 三阶递进

三级递增难度。识别阶段（选择题）→ 填空阶段（补全字母）→ 默写阶段（Game Drop 字符下落游戏）。你只面对自己准备好了的挑战，不给"没学过"的测试。

DESIGN PHILOSOPHY

反课本设计

四条法则，每条都在颠覆传统语言教育。

频率驱动

基于语料库高频词根精选。先掌握覆盖85%日常交流的2000个核心词根，再拓展低频词汇。效率是指数级的。

词根逻辑植入

前缀+词根+后缀=可预测的构词系统。-tion是名词，-able是"可…的"。掌握50个词缀=解锁4000+单词。

拼写韵律编码

拼写模式嵌入16步音序器的节奏骨架。每个音节对应一步，重音获得额外强调。拼写不再是字母序列，而是身体能感受的节奏。

三维记忆闭环

频率筛选(选什么学) → 韵律编码(怎么记住) → 间隔召回(何时复习)。不是单点突破，而是完整的记忆管理系统。

CORE ENGINES

六大引擎，一个体验

每个组件独立设计，无缝集成。纯前端实现，零外部依赖。

高频词根引擎

基于 COCA/BNC 语料库精选的高频词根词缀。按频率分层编排，先学"每天都会遇到的"，不学"十年用一次的"。

Morph Bridge 词素桥

词根词缀级拆解着色。前缀(青)/词根(蓝)/后缀(粉)。逐级点击发声。在"为什么这个词这么拼"和"为什么这么读"之间建立因果映射。

拼写渐进测试

识别(选词根)→填空(补词缀)→默写(完整拼写)三级递进。错误不是惩罚，是下一次正确的触发器——答错自动重播词根韵律。

Leitner Box 间隔复习

5级间隔盒：L0→L1→L2(1天)→L3(3天)→L4(7天)→✅掌握。答错回退L0。localStorage持久化，刷新不丢进度。

Game Drop 拼写下落

词根+词缀按序从顶部下落，9秒内完成拼写。正确→绿色闪烁+得分音效。错误→红色抖动+自动显示词素拆解。拼写测试变成节奏游戏。

韵律人声引擎

en-US-AriaNeural 业界最高评英语女声。词根+例句全Base64内嵌。6轮韵律循环(去人声→30%→100%)，Web Audio API 变速0.55x-1.0x。
